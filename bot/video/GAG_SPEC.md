# 朝の動画「ハプニング → オチ」作成指示書（Claude Code 向け）

この文書は、Claude Code が `bot/video/` で朝の動画を1本ずつ作るための指示書です。
上から順に読み、「作業手順」に従って、未作成の日（下の一覧で【済】の日）を作ってください。

---

## 1. 何を作るか

- SNS（Instagram リール）に毎朝投稿する、縦長 1080×1920・30fps・約12〜15秒の動画。
- 構成：**ハプニング（約5〜6秒・文字なし）→ オチ（ゴリラがフレーズを「ふつうの速さ」→「ゆっくり」で言う）**
- オチの部分（フレーズのカード・ふりがな・ローマ字・英訳・話すゴリラ）は `assemble.py` と `frames.cjs` が自動で作る。**作るのはハプニング部分（`gag_dNN.cjs`）だけ**。
- 1日に1ファイル：`bot/video/gag_dNN.cjs`（NN は2けたの日にち。例：`gag_d08.cjs`）

## 2. 守るルール（必ず守る）

### 2-1. 倫理
- ゴリラは「場面を演じて見せる先生役」。**外国から来た人の役にしない**。
- 出身地・国旗・ジャングル・「道具の使い方を知らない」表現は使わない。
- 「ルールを守らない」「うるさい」など、特定の集団への思いこみにつながる場面を作らない。
- 笑いの理由は、ゴリラの**体の大きさ・力の強さ・ドジ**だけ。人をからかう笑いにしない。
- 人（`person()`）は、特定の国や人種に見えないシンプルな形のまま使う。肌の色や髪型で特定の集団を表さない。
- 防災・けが・病気の回は**笑いにしない**。ゴリラが人を助けるたのもしい場面にし、正しい行動を見せる。

### 2-2. ユニバーサルデザイン
- **文字を使わない**（看板・効果音の文字・セリフも不可）。数字（時計の針、1・1・9のボタン）と世界共通の記号（火の絵、×、指の本数、7つの四角の1週間、十字など）は可。
- 1つの場面で見せるものは1つ。主役（ゴリラ・指している物）を大きく。
- 形には濃いふちどり。**色だけで意味を伝えない**（形・位置・太さでも区別する）。
- 動きはゆっくりめ（大事な動きは0.5秒以上）。**点滅は使わない**。画面のゆれは振幅6px以下。
- 注目させるための丸の印・矢印の印は使わない。指さし・視線・動きで注目させる。

### 2-3. 絵のルール
- ゴリラは必ず `lib.cjs` の `gorilla()` を使う（腕は肩から自然につながる。勝手に別の腕を描かない）。
- 腕を動かすときは `gorilla(x,y,{right:{tx,ty,kind,...}})` のように**目標の位置**を渡す。腕が届く距離は肩から約290px（`U+F`）。届かない目標を渡すと手が途中で止まるので、目標は届く範囲に置く。
- 物を持つときは `kind:'grip'` と `item`（手の向きの座標で描いたSVG）。指さしは `kind:'point'`、手のひらは `'open'`、親指を立てるのは `'thumb'`。
- 体を回す（`rot`）と腕の位置計算がずれる。腕で物をつかむ場面では `rot:0` にする。
- 人の手で物を差し出すときは `person(...,{hand:[x,y]})`（人の座標系）を使い、物もその手の位置に描く。

## 3. 部品（`lib.cjs`）

| 部品 | 使い方 |
|---|---|
| `gorilla(x,y,o)` | ゴリラの上半身。(x,y)=体の中心（基準は (290,1560)）。`o.m`=口の開き 0〜1、`o.blink`、`o.nod`=首を横にふる量（頭だけ動く）、`o.headRot`、`o.rot`=体の傾き（おじぎ等）、`o.dy`=上下、`o.right`/`o.left`=腕の目標 |
| `person(x,y,s,o)` | 人。`o.face`='smile'/'neutral'/'shock'/'happy'、`o.shirt`/`o.shirtLine`=服の色、`o.hair`='short'/'long'/'bun'、`o.apron`、`o.hat`={dx,dy,r}、`o.hand`=[x,y]、`o.thumb`、`o.sweat`=0〜1（汗とおどろきの線）、`o.blown`=0〜1（風で髪がなびく） |
| `seq(t,a,b)` | a〜b秒で 0→1 になる（ゆるやかに） |
| `lerp(a,b,k)` / `cl(v)` | 補間 / 0〜1に収める |
| `svgWrap(背景色, 中身)` | 1080×1920 のSVGにする。中身は全体を1.32倍にして下寄せで表示（座標は 1080×1920 の基準で描く。画面に見えるのはおよそ y=470 より下） |
| `renderGag(OUT,DUR,frame,bgSvg)` | コマ画像を書き出す。`frame(t)` は時刻tのSVG。`bgSvg` はオチの場面の背景（**ゴリラなし**の最後の場面） |

ファイルのひな形（`gag_d03.cjs` などを参考に）：

```js
const L=require('./lib.cjs');const {seq,lerp,cl,gorilla,person,svgWrap}=L;const OUT=process.argv[2];const DUR=5.6;
function scene(t,G=true){ /* 背景・小道具・人・ゴリラ（G のときだけ）を返す */ }
L.renderGag(OUT,DUR,t=>svgWrap('#背景色',scene(t)),svgWrap('#背景色',scene(DUR-0.1,false))).then(()=>console.log('ok'));
```

## 4. 作業手順（1本ごと）

1. 下の「日ごとの指示」を読み、`gag_dNN.cjs` を作る。
2. コマを書き出す：`NODE_PATH=$(npm root -g) node video/gag_dNN.cjs /tmp/gNN`
3. **確認**：時間を分けて6コマほどを1枚に並べた画像を作り（PIL で縮小して並べる）、目で見る。各日の「確認ポイント」と2章のルールをすべて満たしているか確かめる。
4. **弱いところは必ず直す**：見て「わかりにくい」「不自然」「ルールに合わない」と感じた点は、報告だけで終わらせず、直してから3に戻る。
   - よくある問題：腕が体とつながっていない／指が目標を指していない／物が人の顔に重なる／持っている物が手から離れている／主役が小さい・画面外／背景に隠れて見えない
5. 動画にする：`NODE_PATH=$(npm root -g) python3 video/build_gag.py NN` → `out/videos/dayNN_morning.mp4`
6. オチの場面の1コマ（9秒あたり）も確認し、フレーズのカードが背景で読みにくくないか見る。
7. 1週分（6本）できたら、まとめてユーザーに見せる。そのとき、直したところと、まだ直せない点（声など）を短く伝える。
